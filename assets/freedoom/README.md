# Freedoom game data (embedded in the mod's dll)

- **What:** `freedoom1.wad`, Freedoom Phase 1 (the four-episode game), version **0.13.0**. Freedoom is a free replacement for DOOM's game data (levels, art, sounds, music) that works with any DOOM engine.
- **Where it came from:** the Ubuntu 24.04 package `freedoom` 0.13.0-1 (`/usr/share/games/doom/freedoom1.wad`). I could not reach the official release page from the cloud session, so this is the distribution's build of the same release, not the file from the project's zip. SHA-256: `5920dd3f11264075dd1488e57b2617c89da71a425491306718c181de3ecdc8cd`, 28,795,080 bytes. If you want the official file, put it here under the same name, rebuild and rename the extracted copy's version if it differs (`FreedoomData.cs`).
- **License:** BSD 3-clause (Freedoom contributors), apart from `playpal` and `colormap` which are GPL-2+; see `LICENSE.txt`, which is the package's copyright file and is also embedded in the dll so the notice travels with the binary. Project page: https://freedoom.github.io/ , source: https://github.com/freedoom/freedoom
- **How it is used:** both files are embedded in the dll (`DoomedSpire.csproj`, `LogicalName` `freedoom1.wad` and `freedoom-LICENSE.txt`). The engine reads WADs from files, so the first time DOOM opens, the mod writes the embedded copy to `user://DoomedSpire/data/freedoom1-0.13.0.wad` and reuses it afterwards (`src/Host/WadCache.cs`, `src/FreedoomData.cs`).
