# DOOM shareware game data (embedded in the mod's dll)

- **What:** `doom1.wad`, the shareware version of DOOM (episode one, "Knee-Deep in the Dead", 9 levels), version 1.9. This is id Software's original game data: levels, graphics, sound effects and music.
- **Where it came from:** the Ubuntu 24.04 package `doom-wad-shareware` 1.9.fixed-4 (`/usr/share/games/doom/doom1.wad`), taken from id's own release with no modification. MD5 `f0cefca49926d00903cf57551d901abe` (the well-known value for the 1.9 shareware file), SHA-256 `1d7d43be501e67d927e415e0b8f3e29c3bf33075e859721816f652a526cac771`, 4,196,020 bytes. The owner has the same file and can replace this one with theirs.
- **License:** id Software's "Limited Use Software License Agreement" for the shareware version, copied in `LICENSE.txt` (the package's copyright file, also embedded in the dll). Its grant is to *use* the shareware version and it forbids modifying it or making derivative works. The file is therefore embedded **unmodified and whole**. The package notes that the text does not itself grant distribution permission, and includes John Carmack's 1999 e-mail saying "The DOOM shareware wad is freely distributable", which is why Debian and Ubuntu ship it. That is what this mod relies on. It is not legal advice.
- **How it is used:** embedded in the dll (`DoomedSpire.csproj`, `LogicalName` `doom1.wad` and `doom1-LICENSE.txt`). The engine reads WADs from files, so the first time DOOM opens, the mod writes the embedded copy to `user://DoomedSpire/data/doom1-shareware-1.9.wad` and reuses it afterwards (`src/Host/WadCache.cs`, `src/BuiltInWad.cs`). Other games saved by the player in `user://DoomedSpire/wads/` can be chosen instead (`src/Host/WadLibrary.cs`).
- **Music format:** this WAD's music is in id's original MUS format, which `src/Host/MusPlayer.cs` plays. (Freedoom's music is plain MIDI, which also works.)
