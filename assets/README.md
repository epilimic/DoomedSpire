# Where the art and data in this folder came from

- `crt.png`: the old-monitor picture the game is drawn on. Found by the owner, uncredited, on an open-source, free-to-use website.
- `doom_button.png`: the DOOM logo, from id Software (the DOOM name and logo are their trademark).
- `*-faces.png` (one per character): the status-bar faces, painted by the owner, based on the Slay the Spire characters (Mega Crit's art).
- `doom/`: id Software's shareware DOOM1.WAD, unmodified; see `doom/README.md` and `doom/LICENSE.txt`.
- `soundfont/`: the TimGM6mb soundfont (GPL v2); see `soundfont/README.md` and `soundfont/LICENSE.txt`.
