Doomed Spire



Need to release some rage?

Friend taking forever to poop?

Just love DOOM?



Well now you can play DOOM anytime from the map screen! Press the DOOM button and you'll be launched straight to hell. 

I've made some fun tweaks too... The enemies are now STS enemies and keycards are now Wah, Cho, and Ki melodies. Doomguy is whoever you are playing as!

The shareware version of DOOM is included but additional .wad files are supported too. A few different varieties work (Freedoom, Doom II, Plutonia, and a couple others) but only original DOOM has the custom enemies and keycards.

Here's the standard folder locations that steam saves stuff to, yours may differ. Put your wads here.

Linux:
/home/<username>/.local/share/SlayTheSpire2/DoomedSpire/wads/

Windows:
C:\Users\<username>\AppData\Roaming\SlayTheSpire2\DoomedSpire\wads

You'll get a game selection menu when you press the DOOM button if any wads are found in the folder. You can drop back to this menu by quitting any DOOM game from it's own menu.
